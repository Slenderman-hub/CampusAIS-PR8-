# АИС «Умный кампус»: Паспорт артефактов и реализация протоколов

Данный репозиторий содержит программную реализацию архитектурных решений и процессных протоколов, описанных в рамках практической работы №8 для автоматизированной информационной системы «Умный кампус».

## 🎯 Реализованные артефакты и протоколы

1. **Архитектурное решение (ADR-001):** Реализован паттерн Transactional Outbox для асинхронной передачи событий отзыва пропуска в систему СКУД через брокер сообщений (RabbitMQ).
2. **Процессные протоколы:** В проекте применяется стратегия ветвления GitHub Flow. Ветка `main` защищена. Любые изменения вносятся через Pull Request после прохождения CI и Code Review.
3. **Контрактный артефакт:** REST API документирован с помощью OpenAPI 3.1 (генерация через Swagger UI).
4. **Тестовые артефакты:** Бизнес-логика покрыта unit-тестами на базе xUnit.

## 🏗️ Архитектура решения (ADR-001)

Согласно принятому архитектурному решению, прямая синхронная интеграция с legacy-системой СКУД (которая имеет лимиты запросов и не поддерживает идемпотентность) недопустима. Вместо этого используется паттерн **Transactional Outbox**:

*   **`PassService`**: При отзыве пропуска выполняет транзакционное изменение статуса в базе данных и одновременную запись события `PassRevoked` в таблицу Outbox.
*   **`OutboxWorker`**: Фоновый сервис (`BackgroundService`), который асинхронно вычитывает события из таблицы Outbox и публикует их в брокер сообщений.

> **Примечание:** В демонстрационном прототипе инфраструктура RabbitMQ эмулируется фоновым выводом в консоль (для запуска не требуется развертывать Docker-контейнеры). В production-среде вызов в `OutboxWorker` заменяется на `RabbitMQ.Client`.

## 📂 Структура решения

*   `src/Client/` — клиентское приложение (WPF), включая UI, бизнес-логику и API-клиенты.
*   `src/Gateway/` — интеграционный шлюз (ASP.NET Core), включая API, безопасность, синхронизацию и интеграцию.
*   `src/Shared/` — общие DTO и контракты.
*   `tests/` — модульные тесты (xUnit) для клиента и шлюза.
*   `docs/` — проектная документация (исходники диаграмм PlantUML, спецификации OpenAPI, ADR).

## 🚀 Как запустить и продемонстрировать работу

1. Откройте решение `CampusAIS.sln` в Visual Studio.
2. Сделайте проект **`CampusAIS.Gateway.Api`** запускаемым (Set as Startup Project).
3. Нажмите **F5** для запуска. В браузере откроется **Swagger UI**.
4. Найдите эндпоинт **`POST /passes/{id}/revoke`**.
5. Нажмите *Try it out*, введите любой GUID (например, `11111111-1111-1111-1111-111111111111`) и нажмите *Execute*.
6. **Переключитесь в окно вывода Visual Studio (Output -> Debug) или в консоль.** 

Вы увидите логи, подтверждающие работу паттерна:
